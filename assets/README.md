# Karinderya Asset Directory

You can place your image and prototype files directly here:
`c:\2ND-TERM (3RD YEAR)\CCE106\karinderya_mobile_application\public\assets\`

Supported files:
- `adobo.png` / `adobo.svg` (Chicken Adobo)
- `sinigang.png` / `sinigang.svg` (Pork Sinigang)
- `lumpia.png` / `lumpia.svg` (Lumpiang Shanghai)
- `rice.png` / `rice.svg` (Steamed Rice)
- `hero-art.png` / `hero-art.svg` (Hero banner food art)
- `mascot.png` / `mascot.svg` (Karinderya mascot)
- `empty-pot.png` / `empty-pot.svg` (Empty cart / order state)
- `rice-cooker.png` / `rice-cooker.svg` (Menu setup empty state)

Any files placed here can be directly referenced in the app via `/assets/<filename>`.
